# 골든텐 이미지와 레이아웃 방향

## 첫 화면: 과녁 중앙에 꽂힌 화살 한 발

가장 추천하는 방향은 **글씨 없는 과녁 클로즈업**입니다. 사이트 이름의 TEN과 금색을 직접 연결할 수 있고, 특정 선수의 사진을 구하지 않아도 사용할 수 있습니다. 현재는 이 구성을 단순한 정적 SVG 이미지로 구현했습니다. 이미지 위에 문구, 점수 배지, 버튼을 겹쳐 놓지 않습니다.

- 장면: 노란색 10점 영역에 화살 한 발이 꽂힌 순간. 여러 화살, 선수 얼굴, 경기장 관중을 함께 넣지 않습니다.
- 구도: 과녁은 화면 중앙 또는 약간 오른쪽. 화살은 오른쪽 위에서 중앙으로 이어지는 대각선으로 배치합니다. 주요 피사체 주변에 충분한 여백을 둡니다.
- 색감: 배경은 짙은 남색, 과녁은 실제 양궁 과녁의 색을 유지합니다. 노란 중심과 화살 깃이 자연스럽게 강조되도록 합니다.
- 글자: 영문 문구, 10점 배지, 로고, 캡션 등을 이미지에 합성하지 않습니다. 제목과 버튼은 이미지 바깥의 왼쪽 글 영역에만 배치합니다.
- 비율: 가로 5:4 또는 4:3. 오른쪽에 놓을 사진을 고른다면 최소 1600×1200px 정도의 원본을 권장합니다. 모바일에서는 제목 아래에 이미지를 독립적으로 배치합니다.
- 실제 사진을 사용할 경우: 이용 조건이 확인된 사진을 선택하고, 과녁 중심이나 화살이 화면 밖으로 잘리지 않도록 전체 비율을 유지합니다.

### 다른 선택지

1. 활시위를 당기는 선수의 옆모습: 사람의 집중력과 감정이 잘 전달됩니다. 얼굴, 손, 활이 함께 보이는 가로 사진이 필요하며 해당 사진의 이용 조건을 확인해야 합니다.
2. 간결한 과녁 일러스트: 골든텐의 남색·금색과 쉽게 통일할 수 있고 화면 크기에 따라 선명하게 표시됩니다. 현재 적용 방향입니다.
3. 경기장 전경이나 시상대 사진: 대회 분위기는 설명하기 좋지만 작은 화면에서는 인물과 정보가 많아져 첫 화면보다는 블로그 본문에 더 적합합니다.

## 전체 배치

첫 화면 → 짧은 메달 요약 → 주요 결승 다시보기 → 그림으로 보는 관전 안내 → 선수 요약 → 블로그 소개 → FAQ → 출처 → 마지막 MBC CTA.

- 같은 정보를 다시 설명하는 바로가기 카드와 긴 관전 글 묶음을 제거합니다.
- 제목, 설명, 카드의 간격과 폭을 통일합니다.
- 선수 소개는 종목·이름·성적 위주로 짧게 표시합니다.
- 메인의 블로그 글은 작은 썸네일과 제목·한 줄 소개만 보여줍니다. 전체 원문과 이미지 5장은 상세 페이지에 그대로 유지합니다.
- FAQ는 펼침 방식으로 자세한 설명을 숨기고 질문부터 읽게 합니다.

## 규칙 안내: 활의 생김새 + 실제 점수판

리커브와 컴파운드 각각 같은 구조의 카드 한 장으로 설명합니다.

1. 활 그림: 리커브는 휘어진 활 끝, 컴파운드는 양끝의 도르래를 강조합니다.
2. 거리 표시: 70m와 50m를 점선과 작은 과녁 기호로 보여줍니다.
3. 점수판 예시: 리커브 6:2는 세트 승점, 컴파운드 149:145는 화살 점수의 합계임을 시각적으로 구분합니다.
4. 한 줄 규칙: 개인전 기준 6점 선취 / 15발 150점 만점을 각각 표시합니다.
5. 공통 안내: 슛오프는 별도 한 줄 영역으로 설명합니다.

현재 활 그림은 초보자를 위한 단순화된 도식이며 실제 제품이나 선수 장비의 정밀 도면은 아닙니다.
