# 다음 개선 우선순위

1. **전체 출전 명단과 사진 확정**: 사용자가 제공한 프로필 ZIP의 12명을 연결했고 최은규 선수를 추가했습니다. 이후 공식 출전 명단과 최종 대조합니다. 사진은 얼굴과 메달 표시가 잘리지 않는 원본 비율로 표시합니다.
2. **영상 안내 보완**: MBC 방송 한 회차에 여러 경기가 포함되므로, 확인 가능한 경우 경기별 시작 시각이나 회차 제목을 함께 표시합니다. 확인 전 임의 시각을 넣지 않습니다.
3. **긴 블로그 글에 목차 추가**: 메달 결과·결승 결과·선수 성적·주요 기록·일정으로 바로 이동할 수 있게 합니다.
4. **경기 기록 최종 대조**: 경기 날짜·대진·점수·메달을 공식 원문과 대조하고 출처를 연결합니다. 지금은 사용자 제공 원고 기반입니다.
5. **실제 공개 주소 마련**: ZIP을 받아 파일을 여는 과정 없이 방문할 수 있도록 사이트를 배포합니다. 현재 GitHub 저장소는 파일을 받는 주소입니다.
6. **이미지 용량 최적화**: 사진을 받은 후 화면에 필요한 크기와 선명도를 확인하고 용량을 줄여 모바일 로딩 부담을 낮춥니다. 현재 단일 HTML에는 이미지 원본이 포함되어 있습니다.
