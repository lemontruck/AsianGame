# 골든텐 · GOLDEN TEN

2026 아시안게임 양궁을 주제로 한 수업 실습 웹사이트입니다.

## 설치 없이 사이트 확인하기

1. GitHub 화면의 초록색 **Code** 버튼을 누르고 **Download ZIP**을 선택합니다.
2. 받은 ZIP 파일의 압축을 풉니다.
3. 폴더 안의 **골든텐-사이트.html** 파일을 Chrome 또는 Edge로 엽니다.

`index.html` 대신 **골든텐-사이트.html**을 열어주세요. 이 파일에는 블로그 이미지까지 모두 들어 있어 별도 설치가 필요 없습니다. 메인과 블로그를 이동하고, 블로그 이미지를 클릭해서 크게 볼 수 있습니다. MBC 등 외부 페이지로 이동하려면 인터넷 연결이 필요합니다.

이 저장소 주소는 코드와 파일을 받는 곳이며, 웹사이트의 공개 배포 주소는 아닙니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm ci
npm run dev
```

## 빌드 및 배포 확인

```sh
npm run build
npm run preview
```

`dist/` 폴더를 정적 웹 호스팅에 배포하면 됩니다. 실제 공개 주소는 배포 후 결정됩니다.

## 페이지

- `/` : 메인 소개, 기본 규칙, 주요 결승, 블로그 소개
- `/matches/` : 주요 결승 6경기의 선수 사진, 점수 설명, 관전 포인트, MBC 다시보기
- `/archery-rules/` : 리커브·컴파운드 규칙 아코디언, 비교표, 실제 스코어 예시
- `/blog/` : 썸네일이 있는 블로그 목록
- `/2026-asian-games-archery-results` : 사용자 작성 양궁 결과 분석 글

메인 양궁 과녁 그래픽은 자체 제작 SVG입니다. 블로그의 5개 인포그래픽은 사용자가 제공한 PDF에서 원본 그대로 추출했습니다. 블로그 이미지를 누르면 원본 크기의 확대 창이 열립니다. `content/article-images.json`에 PDF 페이지와 각 이미지의 대응 관계가 기록되어 있습니다. 선수 사진은 사용자가 제공한 공식 프로필 ZIP의 원본 파일을 사용합니다. Pretendard는 jsDelivr에서 로드되며 연결할 수 없으면 시스템 글꼴로 표시됩니다.

경기 결과와 영상 링크는 사용자 기획 자료를 바탕으로 입력되었습니다. 원문 기록 및 영상의 대회명·수록 경기·이용 가능 여부는 공개 전에 최종 확인해야 합니다. 전체 대진표나 전체 메달 집계는 제공하지 않습니다. 마지막 CTA는 MBC 2026 아이치·나고야 아시안게임 다시보기 목록으로 연결되며, 영상은 MBC 외부 사이트에서 재생됩니다.

단일 HTML 확인 파일은 `python scripts/export-preview.py`로 갱신합니다. PDF에서 추출한 이미지까지 파일 안에 포함되므로 별도의 이미지 폴더 없이 열 수 있습니다.

## 메인 페이지 구성

첫 화면 안내 → 짧은 메달 요약 → 주요 결승 다시보기 → 그림으로 보는 양궁 한눈에 → 선수 요약 → 블로그 소개 → MBC 다시보기 CTA → 하단 FAQ·공식 출처 → 학습용 안내 순서로 구성합니다.

경기별 다시보기는 금색 버튼으로 표시합니다. 첫 화면은 문구가 겹치지 않는 과녁 정지 이미지 한 장으로 구성하며, 모션과 재생 버튼을 제거했습니다. 관전 안내는 리커브·컴파운드 활 도식과 점수판 예시를 사용합니다. 상세한 이미지 선정 기준은 `docs/이미지와-레이아웃-방향.md`에 정리했습니다.

선수 소개는 사진 영역을 포함한 자동 가로 슬라이드입니다. 명단과 사진 경로는 `athletes.js`의 `athleteRoster`에서 관리합니다. 사용자가 제공한 `선수프로필.zip`의 원본 파일명을 기준으로 12명을 연결했습니다. 기존 명단에 없던 최은규 선수를 추가했으며, 제공되지 않은 성적은 임의로 기입하지 않았습니다. 사진의 2:3 원본 비율과 메달 표시를 자르지 않고 유지합니다. `content/athlete-photos.json`에 원본 파일명과 연결 정보를 기록했습니다.

블로그 목록은 PC 3열, 태블릿 2열, 휴대폰 1열입니다. `src.js`의 `blogPosts`에 게시글 데이터를 추가하면 게시글 수와 목록에 함께 반영됩니다. 미작성 글이나 빈 카드는 표시하지 않습니다.

## 게시글 정보 구조

각 글은 제목(`title`), 요약(`summary`), 대표 이미지(`thumbnail`)와 대체 설명(`thumbnailAlt`), 발행일(`publishedAt`, YYYY-MM-DD), 상세 주소(`href`), 분류(`category`), 읽는 시간(`readingTime`)을 가집니다.

현재 글의 발행일은 사이트 최초 등록일인 2026-10-22로 기록했습니다. 발행일은 목록·메인 소개·글 상세에 같은 데이터로 표시됩니다. 새로운 글을 추가할 때는 이 정보와 본문, 상세 페이지를 함께 등록합니다. 사이트 내부의 글쓰기 관리자 화면은 제공하지 않습니다.

대표 MBC 다시보기 CTA는 본문 직후에 한 번 표시됩니다. 메인의 FAQ와 공식 출처는 CTA 아래 보조 정보 영역에 배치합니다. 블로그 목록과 상세 페이지에는 같은 대표 CTA와 학습용 안내를 표시합니다.

선수 슬라이드는 화면에 들어오는 즉시 별도 조절 버튼 없이 천천히 순환합니다. 마우스를 올려놓기만 해도 멈추던 진입 지연을 제거했습니다. 마우스 드래그·터치 스크롤로 직접 넘길 수 있으며, 조작 없이 약 3초가 지나면 자동으로 다시 움직입니다. 키보드로 조작하는 동안과 기기의 동작 줄이기 설정에서는 정지합니다. 자동 넘김은 해당 영역이 보일 때만 실행되며 페이지 이동 시 정리합니다. 화면 낭독기에 반복 목록이 중복으로 읽히지 않도록 구성했습니다.

최종 CTA는 PC와 모바일에서 넓은 영역·큰 제목·큰 버튼을 사용합니다. FAQ와 공식 출처는 CTA 뒤에 표시됩니다.

상단 메뉴는 스크롤 중에도 표시되며, 현재 구역을 짙은 남색 배경으로 강조합니다. 경기 카드는 제공된 원본 선수 사진, 한 줄 관전 포인트, 국가가 구분된 점수판으로 구성합니다. 경기 자료는 기존 사용자 원고 기준입니다.

메인 주요 결승은 자동으로 움직이지 않는 6개 요약 목록입니다. 종목·선수·메달·국가별 최종 점수를 표시하고, 각 행의 ‘경기 자세히 보기’는 `/matches/#경기ID`로 연결됩니다. ‘주요 경기 전체 보기’와 상단 ‘주요 경기’ 메뉴도 `/matches/`로 연결됩니다. 상세 페이지는 선수 사진, 상대, 점수 읽는 법, 관전 포인트, 기존 MBC 회차 링크를 표시하는 고정 카드로 구성합니다. 선수 소개의 자동 슬라이드는 유지합니다.

## 경기 규칙 가이드

상단 ‘경기 규칙’ 메뉴와 메인 ‘양궁 한눈에’의 ‘자세한 규칙 알아보기’ 버튼을 `/archery-rules/`에 연결했습니다. `rules.js`가 문구·비교표를 관리합니다. 리커브 5개·컴파운드 5개 질문은 기본 HTML의 `<details>`와 `<summary>`로 구성하며, 최초에는 모두 닫혀 있습니다. 종목 소개는 펼치지 않아도 읽을 수 있습니다. 비교표와 실제 점수 예시 다음에는 기존 결과 분석 글로 이동하는 내부 링크를 제공합니다.

`npm run build`는 `scripts/export-rules.mjs`를 먼저 실행해 질문과 답변 전체가 초기 HTML에 포함된 `archery-rules/index.html`을 생성합니다. JavaScript 실행 전에도 본문을 읽을 수 있습니다. 이 구조가 검색 노출을 보장하지는 않습니다. 단일 HTML 파일에서도 새 페이지와 목차·블로그 이동을 지원합니다. 새 문구를 수정한 뒤에는 빌드와 `python scripts/export-preview.py`를 함께 실행합니다.

`matches.js`의 `matchData`가 요약 목록과 상세 페이지의 공통 경기 데이터입니다. 기존 점수·선수·MBC 회차는 유지하고 규칙에 기반한 설명을 추가했습니다. `npm run build`는 `scripts/export-matches.mjs`도 실행해 전체 경기 설명이 초기 HTML에 포함된 `matches/index.html`을 생성합니다. 단일 HTML 파일에도 상세 페이지·경기별 바로가기·페이지 제목과 설명이 포함됩니다.

## 첫 화면 안내와 사진 확대·출처

첫 화면에 ‘한국 양궁 주요 결승 6경기, 결과부터 다시보기까지.’를 표시해 방문 가치를 설명합니다. 메인의 짧은 안내 메뉴와 영역은 ‘양궁 한눈에’로, 별도 상세 페이지는 ‘경기 규칙’으로 구분합니다.

선수 소개와 주요 경기 페이지의 프로필 사진을 누르면 이름·종목·기획 원고상의 성적·사진 제공 경로가 있는 확대 창이 열립니다. 원본 2:3 사진과 메달 표시는 유지합니다. 확대 중에는 자동 슬라이드를 멈추며, 닫기 버튼·Escape·배경 클릭으로 닫을 수 있습니다. 마우스 드래그는 확대 클릭과 구분하고, 시각적 반복 목록에서도 사진 클릭이 동작합니다. 반복 목록은 키보드와 화면 낭독기에서는 제외합니다.

제작자가 알려준 출처에 따라 선수 사진은 대한양궁협회 국가대표 소개 페이지의 프로필 사진으로 표시하고 링크를 연결합니다. 하단 ‘자료·사진 출처’는 경기 기록·규칙·선수 정보의 참고처인 World Archery·대한양궁협회, MBC 영상 연결, 선수 사진 출처를 구분합니다. 블로그 도표의 기존 PDF·쪽수 캡션은 유지합니다. 사진은 사용자가 제공한 ZIP의 원본 파일을 그대로 사용합니다.

## 최종 최적화

- 상단 홈 탭은 제거하고 로고를 홈 링크로 사용합니다. 첫 화면의 블로그 보조 링크를 제거하고, 주요 경기 페이지의 반복 규칙 링크 6개를 공통 안내 1개로 모았습니다. 경기 상세·전체 보기·규칙 상세·사진 확대·대표 MBC CTA는 유지합니다.
- ‘맨 위로’ 버튼은 오른쪽 아래에 48px(휴대폰 44px) 원형으로 표시합니다. 600px 아래로 스크롤했을 때 나타나며 확대 창에서는 숨깁니다. 동작 줄이기 설정에서는 즉시 이동하고 키보드 초점을 로고로 돌려줍니다.
- 도표 5개는 원본 크기와 픽셀을 유지한 무손실 WebP로 제공하고, PNG 원본은 `content/original-article-images/`에 보관합니다. 원본은 정적 배포 폴더에 복사하지 않습니다. 목록용 메달 비교 썸네일은 640×480px 파일로 분리합니다.
- 단일 HTML은 공유 이미지 사전을 사용해 각 이미지를 한 번만 저장합니다. 기존 13.85MB에서 약 7.96MB로 줄었습니다. 사진 확대에서도 같은 내장 이미지를 사용하며 로컬 이미지 파일 요청이 필요하지 않습니다.
- 선수 자동 슬라이드는 화면 밖·비활성 탭·확대 창·동작 줄이기 설정에서 애니메이션 프레임 자체를 예약하지 않습니다. 크기는 변경될 때만 측정하고, 실제 움직일 때만 프레임을 실행합니다. 직접 넘긴 뒤에는 3초 뒤 재개합니다.
- 사용하지 않는 경기 슬라이드 분기와 삭제한 버튼의 스타일을 정리했습니다. 단일 HTML에서 ‘맨 위로’로 이동한 뒤 같은 메뉴를 다시 눌러도 해당 구역으로 이동합니다.

## Vercel 배포

`vercel.json`에서 Vite 빌드와 `dist` 출력 폴더를 설정했습니다. 정적 HTML 페이지 5개를 각각 제공하므로 모든 주소를 메인으로 돌리는 SPA 재작성 규칙은 사용하지 않습니다. 별도 환경 변수는 필요 없습니다. `cleanUrls`를 적용하고 끝 슬래시는 제거합니다.

1. https://vercel.com/new 에서 GitHub 계정으로 로그인합니다.
2. `lemontruck/AsianGame` 저장소를 선택해 **Import**합니다. 목록에 없으면 GitHub 연결 권한에서 해당 저장소 접근을 허용합니다.
3. 프로젝트 이름을 `golden-ten-2026`, 배포 브랜치를 `main`으로 두고 **Deploy**를 누릅니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다.
4. 배포 완료 화면의 실제 주소에서 `/`, `/matches`, `/archery-rules`, `/blog`, `/2026-asian-games-archery-results`를 확인합니다. 정확한 도메인은 프로젝트 생성 결과에 따라 결정됩니다.

GitHub 연결 후에는 `main`에 수정본이 올라갈 때 자동으로 다시 배포됩니다. `.vercelignore`는 로컬 확인용 대용량 HTML, PNG 보관 원본, 문서와 설치 폴더를 업로드에서 제외합니다. 웹사이트가 사용하는 사진·도표는 `public/`에 포함됩니다.
